# 🌊 Simple USGS Flood Data Monitor

A web application designed to help construction sites quickly review flood-related data and warnings by date using USGS data.

---

## ✨ About the Project

The **Simple USGS Flood Data Monitor** was created with construction sites in mind.

Flood conditions can create safety concerns and affect construction operations. This application gives users a simple way to select a date and view flood-related information recorded across monitoring sites in the United States.

Instead of searching through large amounts of data manually, the application retrieves and organizes the information for the selected date.

---

## 🔎 How It Works

1. The user selects a **date**.
2. The application sends the selected date to the API.
3. The API retrieves flood-related data associated with that date.
4. The application displays the flood warnings and reference information for the monitoring sites.
5. JavaScript processes the returned data and calculates how many warnings were recorded for that day.
6. The results are displayed directly on the page for the user.

---

## 🏗️ Who Is It For?

This application was designed with **construction sites and construction teams** in mind.

Flood information can help teams stay aware of conditions that may affect:

- Construction sites
- Structures
- Work areas
- Site safety
- Daily operations

By selecting a specific date, users can quickly review the flood information returned for that day.
